# Add a read-only view

Read the schema and views.json. Translate the requested question into a parameter-free SELECT over the business records. Add an entry to views.json with a name, title and sections containing title and sql. Run npm run view and open the output. Keep brand.json as the branding source. Never add forms, actions, scripts or a server. If new data is needed, use customise to add a migration and tests first.
