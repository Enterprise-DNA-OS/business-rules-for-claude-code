# Write the Monday rule review

Run `npm run rules -- weekly-review`. Add `--json` when combining results. Resolve names case-insensitively or by id prefix. If ambiguous, show candidates and ask the operator to identify the record.

Read `reviews-due`, `decisions` and `exceptions` separately if a fact needs detail. Summarise owners, overdue work, unmatched decisions and proposed next steps. Never approve a change as part of this review.

Report only what the output proves. Drafts stay in `drafts/`. Nothing sends.
