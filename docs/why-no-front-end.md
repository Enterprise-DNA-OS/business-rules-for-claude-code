# Why no front end

Business rules, test examples, review dates and exceptions are records. A coding agent can read them and run a deterministic evaluator. You can inspect the definition and every matched row. There is no model call in the evaluator.

A visual editor provides drag and drop, simultaneous authoring, mobile access and immediate interactive feedback. This project provides none of those. The embedded database is local and single-operator. Shared use needs a managed database and authentication suited to the business. HTML views and documents are read-only snapshots, not live applications.

There is no hosted Solver API, connector platform, automatic scaling, scheduled job runner or vendor uptime commitment in the free base. Enterprise DNA scopes those connections, hosting and interfaces into the installed version. Local execution works without network access after dependencies are installed. Do not use these operational examples for regulated decisions.
